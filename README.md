# Pixonaut for WooCommerce

Connects a WooCommerce store to Pixonaut: customers
personalise products on the product page, and paid order lines become
printshop orders through Pixonaut.

- Merchants: [docs/merchant](docs/merchant/index.md), starting with
  [getting started](docs/merchant/getting-started.md)
- Developers: [docs/developer](docs/developer/index.md), starting with
  [local setup](docs/developer/local-setup.md); before opening a pull
  request, read [contributing](docs/developer/contributing.md)
